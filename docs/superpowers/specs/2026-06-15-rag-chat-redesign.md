# RAG Chat Redesign — 课程问答重构

**Date**: 2026-06-15
**Status**: approved
**Scope**: 重构 RAG 问答系统 + 独立聊天页面

## Problem

当前课程问答体验差：回答质量低、不够耐心、缺少例子、和教材脱节、无对话历史。根因有三层：

1. **Prompt 太简陋**：硬编码在 chat.py，没用 tutor_base 人格，temperature 0.7 太高，无 few-shot，无对话历史
2. **检索质量差**：TF-IDF 关键词匹配，top_k=3 太少，无 score 过滤，English 只有 37 chunks
3. **UI 分散**：每个课程卡片一个聊天按钮，弹窗体验差

## Goals

- 回答风格：**简洁实用型** — 一句话定义 + 生活例子 + 鼓励练习
- 统一导航入口：顶部 `💬 课程问答`，独立聊天页面
- 支持全部科目（默认）或指定科目检索
- 对话历史记忆（最近 6 轮）
- 流式输出保持打字机效果

### 检索策略

- **全部科目模式**：并发搜索 math + english retriever，合并结果按 score 排序取 top_k
- **指定科目模式**：只搜索目标科目
- **score 阈值**：< 0.05 过滤
- **参数调整**：top_k: 3 → 5，每段截断: 600 → 800 字符
- 每个检索结果带 `subject` 标签，注入 prompt 时标注来源

### Prompt 设计

融合 `tutor_base.yaml` 人格，新增 `prompts/rag_chat.yaml`：

- 系统身份：小教练，耐心鼓励的 AI 老师，学生 Jimmy 12 岁七年级
- 回答格式要求（few-shot 示例驱动）：
  1. 一句话直接回答问题
  2. 一个生活例子帮助理解
  3. 一句鼓励或建议（如"试试做几道题"）
  4. 总字数 150-300 字
- 对话历史注入最近 6 轮
- 基于教材上下文回答，标注来源
- temperature: 0.3, max_tokens: 800
